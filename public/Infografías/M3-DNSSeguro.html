Cómo funciona un DNS seguro

Un cambio simple en la configuración de tu red que bloquea sitios maliciosos antes de que carguen.

Opciones de DNS seguro recomendadas
OpenDNS (Cisco) 208.67.222.222 · 208.67.220.220

Gratuito para uso personal. Bloquea sitios maliciosos y de phishing conocidos.

Cloudflare DNS for Families 1.1.1.3 · 1.0.0.3

Gratuito. Bloquea malware y contenido para adultos. Excelente para hogares con menores.

Google Public DNS 8.8.8.8 · 8.8.4.4

Gratuito, rápido y confiable. No tiene filtrado de contenido malicioso por defecto.

Cómo activarlo
Android

Configuración → Redes e internet → DNS privado. Escribe: dns.opendns.com o 1dot1dot1dot1.cloudflare-dns.com

iOS

Requiere una app de configuración de DNS o perfil de red. Cloudflare ofrece la app "1.1.1.1" gratuita.
