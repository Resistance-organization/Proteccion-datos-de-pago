Los datos que protegemos
No todos los datos de una tarjeta tienen el mismo nivel de restricción. Esto es lo que debes saber.
"Te doy mis datos: el número de mi tarjeta es 4532 8812 3344 5566, el nombre es Carlos Andres Mejía, vence en 09/27 y el código de seguridad es 741."
Se pueden almacenar, solo con controles específicos
Número de tarjeta (PAN)
Los 16 dígitos del frente. Ej: 4532 8812 3344 5566
Nombre del titular
El nombre impreso. Ej: Carlos Andres Mejía
Fecha de vencimiento
Mes y año. Ej: 09/27
Nunca se pueden almacenar — sin excepciones
Código de seguridad (CVV/CVC)
Los 3 o 4 dígitos del respaldo. Ej: 741
Datos de banda magnética o chip
La información codificada en la banda o el chip.
PIN del cliente
El código secreto que ingresa en un datafono.
Regla de oro Si para hacer tu trabajo necesitas el CVV o el PIN del cliente, algo en ese proceso está mal. Esos datos nunca deben salir de la transacción.
Fuente: PCI DSS v4.0.1, Requisito 3 — Protección de datos de cuenta almacenados. PCI Security Standards Council, junio 2024.
