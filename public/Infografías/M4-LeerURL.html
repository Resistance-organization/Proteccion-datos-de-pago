Disección de URL

Cómo leer una URL en 5 segundos antes de hacer clic

https://www.bancolombia.com.co/personas/productos
'https://' Protocolo seguro

Necesario pero no garantiza legitimidad.

'www.bancolombia.com.co' El dominio

La parte más crítica. Debe coincidir exactamente con el sitio oficial.

'/personas/productos' La ruta

Da contexto pero no es el elemento crítico.

Ejemplos fraudulentos
bancolombia-seguro.comEl dominio oficial es bancolombia.com.co
bancolombia.com.co.verificacion.netEl dominio real es "verificacion.net"
bancol0mbia.comLa "o" fue reemplazada por un cero (typosquatting)
bit.ly/bancol-seguroEnlace acortado: oculta el destino real
Cómo verificar sin abrir
Celular

Mantén presionado el enlace (sin tocar) para ver la URL completa.

Computador

Pasa el cursor por encima sin hacer clic. La URL aparece en la barra inferior.

Enlace acortado

Agrega "+" al final de una URL de bit.ly para ver el destino real.

Herramienta

VirusTotal (virustotal.com) permite pegar una URL y verificar si es maliciosa.
